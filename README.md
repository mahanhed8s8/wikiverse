# WikiVerse 🧠🌌

**WikiVerse** is an experimental 3D knowledge interface that reimagines how people explore Wikipedia.

Instead of reading pages or navigating lists, WikiVerse lets users **explore ideas as connected concepts in 3D space**, learning through relationships, context, and movement.

## 🧠 What Is WikiVerse?

Wikipedia is one of the greatest knowledge resources ever created — but it is designed for **linear reading**.

WikiVerse transforms Wikipedia into a **spatial learning experience** where:
- Articles become **concept orbs**
- Relationships become **connections**
- Understanding is represented by a central **Brain node**
- Learning happens by **exploration**, not scrolling

---

## 🔗 How It Works

- Each concept is visualized as a node in 3D space  
- Nodes are connected to a central Brain representing understanding  
- Clicking a concept reveals contextual information  
- Wikipedia images are integrated directly into the visualization  
- The interface adapts based on what you explore  

There are:
- ❌ No folders  
- ❌ No trees  
- ❌ No page hierarchies  

Only ideas and relationships.

---

## ✨ Features

- Real Wikipedia data (REST API)
- 3D concept visualization
- Semantic connections between ideas
- Central Brain node explaining WikiVerse
- Contextual summaries instead of pages
- WebGL-powered interaction
- Designed for intuitive learning

---

## 🎯 Project Goals

- Make learning **visual and intuitive**
- Reduce cognitive overload from traditional encyclopedias
- Encourage curiosity-driven exploration
- Rethink how large knowledge systems are presented
